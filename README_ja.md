# Redmine Pinned Issues Plugin

[English version / 英語版はこちら](README.md)

## 概要

このプラグインは、Redmineのチケット一覧画面で、特定のチケットを「ピン留め」して常に上部に表示させる機能を追加します。Twitterの固定ツイートのように、重要なチケットをチームメンバーに周知させるのに役立ちます。

有効期限の設定や、ロールベースの権限管理、プロジェクトごとの機能ON/OFFにも対応しており、柔軟な運用が可能です。

## 主な機能

* **チケットのピン留め/解除**: 特定のチケットを一覧の上部に固定したり、それを解除したりできます。
* **優先表示**: ピン留めされたチケットは、ユーザーがどのようなソート順を選択していても、常に一覧の最上部にまとめて表示されます。
* **有効期限**: ピン留めに有効期限を9種類のプリセット（30分、1/4/8時間、1/3日、1週間、1ヶ月、無期限）から設定でき、期限が来ると自動的にピン留めが非表示になります。
* **権限管理**: 「チケットをピン留めできる」権限を特定のロールにのみ付与できます。
* **プロジェクトモジュール**: プロジェクトごとに、ピン留め機能自体を有効化/無効化できます。
* **視覚的インジケータ**:
  * ピン留めされた行は背景色でハイライト（奇数行/偶数行で色を分けて設定可能）。
  * チケットの題名前に 📍 アイコンを表示（一覧画面・詳細画面の両方）。
* **カラー設定**: 背景色とアイコン色はプラグイン設定画面から自由にカスタマイズ可能。
* **右クリックメニュー操作**: すべての操作は右クリックメニューから実行でき、期限選択はサブメニュー形式。画面遷移やモーダルダイアログなしに、Ajaxでその場で完了。
* **ピン留め内の並び順**: ピン留めされたチケット間では、無期限のものを最上部に、残り時間が長いものから順に表示。

## 動作要件

* Redmine 6.0以降（6.1にも対応）
* Ruby 3.2以降
* Ruby on Rails 7.2
* PostgreSQL 16（他のDBも動作する可能性はありますが、公式にはテストしていません）

## インストール手順

1. Redmineのpluginsディレクトリに移動してclone します

   ```bash
   cd /path/to/redmine/plugins
   git clone https://github.com/seraph3000/redmine_pinned_issues.git
   ```
2. Redmineのルートディレクトリに移動し、以下のコマンドを実行してデータベースのマイグレーションを行います。

   ```bash
   # 本番環境の場合
   bundle exec rake redmine:plugins:migrate RAILS_ENV=production

   # 開発環境の場合
   bundle exec rake redmine:plugins:migrate RAILS_ENV=development
   ```
3. RedmineのWebサーバーを再起動します。

   ```bash
   # 例: passenger を利用している場合
   touch /path/to/redmine/tmp/restart.txt
   ```

## セットアップと設定

インストール後、機能を利用するためには以下の設定が必要です。

### 1. 権限の設定（Redmine管理者向け）

Redmineの管理者が、どのロールにピン留め操作を許可するかを設定します。

1. **[管理] > [ロールと権限]** に移動します。
2. 権限を与えたいロール（例：「開発者」「管理者」など）をクリックします。
3. 「チケットトラッキング」の項目内にある「**チケットをピン留め**」にチェックを入れます。
4. [保存] ボタンをクリックします。

### 2. モジュールの有効化（プロジェクト管理者向け）

各プロジェクトの管理者が、自分のプロジェクトでピン留め機能を有効にする必要があります。

1. 機能を有効にしたいプロジェクトに移動します。
2. **[設定] > [モジュール]** タブを開きます。
3. 一覧の中にある「**チケットのピン留め**」にチェックを入れます。
4. [保存] ボタンをクリックします。

### 3. 表示色のカスタマイズ（任意）

ピン留め行の背景色とアイコン色は、プラグインの設定画面から変更できます。

1. **[管理] > [プラグイン]** に移動します。
2. Redmine Pinned Issues プラグインの「設定」をクリックします。
3. カラーピッカーまたは16進数コードで以下を調整します：
   * ピン留め行の背景色（奇数行）
   * ピン留め行の背景色（偶数行）
4. [保存] ボタンをクリックします。「デフォルトに戻す」で初期値に戻せます。

## 利用方法

1. チケット一覧画面で、ピン留めしたいチケットを右クリックします。
2. コンテキストメニューから「**このチケットをピン留め**」にマウスを合わせ、表示されるサブメニューから期間を選択します：
   * 無期限
   * 1ヶ月 / 1週間 / 3日 / 1日
   * 8時間 / 4時間 / 1時間 / 30分
3. 画面遷移なしで即座にピン留めされます。
4. 解除する場合は、再度右クリックして「**ピン留めを解除**」を選択します。

ピン留めされたチケットは題名前に 📍 アイコンが付き、行の背景色がハイライトされます。詳細画面でも同様に題名横にピンアイコンが表示されます。

## Rakeタスク

メンテナンスや状況確認のためのRakeタスクを複数用意しています。

```bash
# 利用可能なタスク一覧を表示
bundle exec rake redmine:pinned_issues:help RAILS_ENV=production

# 現在のピン留め状況（合計/有効中/期限切れ件数）を表示
bundle exec rake redmine:pinned_issues:status RAILS_ENV=production

# 有効中のピン留め一覧を表示
bundle exec rake redmine:pinned_issues:list RAILS_ENV=production

# 期限切れのピン留めレコードをDBから削除
bundle exec rake redmine:pinned_issues:cleanup RAILS_ENV=production
```

### 定期クリーンアップ（推奨）

期限切れのピン留めは外れて通常のソート順の位置に戻りますが、DB上にはレコードが残り続けます。cronに以下を登録して定期的に物理削除することを推奨します。

```cron
# 毎日3:00に期限切れピン留めを削除
0 3 * * * cd /path/to/redmine && /usr/bin/flock -xn /tmp/redmine_pinned_issues_cleanup.lock -c 'RAILS_ENV=production bundle exec rake redmine:pinned_issues:cleanup'
```
